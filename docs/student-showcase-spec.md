# 学员展示模块设计规范（AI编程培训主题）

- 更新日期：2026-09-16
- 位置建议：首页核心区（Hero 后第一屏 或 与课程体系并列）
- 核心目标：用“滚动学员信息”建立可信赖感与成果感，强化 AI 编程培训主题

---

## 1. 模块目标

1. 快速传递“真实学员 + 真实去向”的信任信号
2. 展示学校背景与就业结果，提升转化率
3. 保持 Ivory 白金极简风格的高级感与可读性

---

## 2. 信息字段（单条学员简要信息）

单条学员信息建议固定为 4 个核心字段，保持“一眼可读”。

- `avatar`：学员头像（优先正方形，1:1）
- `name`：学员姓名（可选展示，脱敏时可只显示“姓+同学”）
- `school`：学校名称（如“XX大学”）
- `grade`：年级（如“大三/研一/2026届”）
- `company`：就业/实习公司（如“字节跳动 / 某AI公司 / 互联网企业”）

### 可选扩展字段（不建议喧宾夺主）
- `track`：课程方向（如“AI全栈 / LLM应用 / MLOps”）
- `tag`：标签（如“已入职 / 实习转正 / 重点本科”）
- `testimonial_short`：一句话反馈（10–16字）

---

## 3. UI 规格建议（卡片 + 滚动条）

### 3.1 卡片（Student Card）
- 外形：横向卡片
- 宽度：建议 300–360px（桌面端）
- 高度：固定 72–88px（保证滚动密度与整齐感）
- 圆角：12px
- 背景：`#FFFFFF`
- 边框：`#E5E7EB`
- 阴影：默认 `0 1px 2px rgba(0,0,0,0.04)`，悬浮 `0 6px 24px rgba(0,0,0,0.06)`
- 内边距：12–16px

### 3.2 头像规范
- 尺寸：40–48px（建议 44px）
- 形状：圆角方形（8px）或圆形均可（推荐圆角方形，更现代）
- 图片比例：1:1
- 容错：无图时显示姓名首字母 + 浅青底（`#E0F2FE`）

### 3.3 文字规范
- 姓名：14–16px，字重 600，颜色 `#111827`
- 学校+年级：13px，颜色 `#6B7280`
- 公司：13–14px，颜色 `#111827`（可加“已入职”标签）
- 标签（tag）：浅青底 `#E0F2FE`，文字 `#0EA5E9`，pill 圆角

### 3.4 滚动方式（Marquee / Ticker）
- 桌面：水平自动滚动（无缝循环）
- 移动端：单列竖向自动滚动（避免横向拥挤）
- 滚动速度：慢速，约 30–50px/s（保证可读）
- 暂停交互：鼠标悬浮暂停，触屏长按暂停
- 无障碍：提供“暂停/播放”按钮

---

## 4. 视觉样式（与 Ivory + 科技青统一）

- 模块标题区：
  - 大标题（中文）+ 副标题（一句话说明）
  - 可在标题旁加“数据统计条”：累计学员数 / 覆盖院校 / 入职企业数
- 卡片排列：
  - 1 行多卡片横向滚动（桌面推荐 3–4 卡可见）
  - 避免卡片信息过载，保持简洁

### 4.1 示例布局（桌面）
- 区块宽度：1280px max
- 滚动视口高度：约 96–120px
- 卡片间距：12–16px

### 4.2 示例布局（移动端）
- 单列卡片滚动（垂直）
- 卡片宽度：100%
- 高度可略增至 96–110px

---

## 5. 数据与隐私建议

- 头像与姓名需获得授权（建议提供“脱敏展示”模式）
- 脱敏策略：
  - 姓名显示为“张同学 / L同学”
  - 公司可保留品牌名或“头部互联网企业”占位
- 数据来源建议：
  - 学员授权表单
  - 入职证明（可选）
  - 合作院校名单（可做汇总指标）

---

## 6. 交互与体验细节

- 滚动动画需顺滑，避免卡顿（CSS transform 优先）
- 卡片 hover 可轻微抬升（影深变化），不做闪烁特效
- 提供“查看更多学员案例”入口（跳转到学员案例详情页）
- 顶部统计数字可做轻计数动画（进入视口时一次计数）
